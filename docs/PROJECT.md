# Свадебное приглашение Дениса и Вероники

Документ для продолжения работы в новом чате или в другой нейросети. Правила работы лежат в [CLAUDE.md](../CLAUDE.md) и [AGENTS.md](../AGENTS.md), их нужно соблюдать.

## Что это

Статичный сайт-приглашение: гость видит лавандовый занавес с сердцем из света, нажимает на экран, половины занавеса разъезжаются, и открывается страница с фото пары. Идея взята из видео-референса заказчика. Сборки и зависимостей нет, это обычные HTML, CSS и JavaScript.

## Пожелания заказчика к оформлению

Первая версия с конвертом и тёмными фонами не подошла. Заказчик просит:

- Только нежные светлые оттенки, ничего режущего глаз. **Тёмных фонов не добавлять.**
- Открытие как в видео-референсе, а не конверт.
- На первом экране сбоку фото пары.
- Живое приглашение: не просто цвет сбоку, а картинки, которые появляются.
- Анкету не трогать, она очень понравилась.

```text

assets/fonts/              шрифты Cormorant, Manrope и рукописный Great Vibes в проекте
assets/img/                занавес и предметы на прозрачном фоне (WebP)
assets/photos/couple.jpg   фото пары на первом экране, квадратное
assets/photos/*            оригиналы лежат здесь же, но закрыты в .gitignore; публикуются только couple*.jpg
assets/og.png              картинка превью ссылки, снята с экрана занавеса
assets/svadba-*.ics        событие для календаря, время в UTC
.nojekyll                  GitHub Pages отдаёт файлы как есть
.gitattributes             сохраняет окончания строк CRLF в файле календаря
.claude/                   локальные настройки и скилл, в репозиторий не идут
```

## Частые правки

| Задача | Где менять |
|---|---|
| Цвета дресс-кода после решения декоратора | `css/style.css`, переменные `--dress-1` ... `--dress-5` в `:root` |
| Цвета страницы и занавеса | `css/style.css`, блок «ПАЛИТРА СТРАНИЦЫ»; цвет занавеса задан самой картинкой `assets/img/curtain.webp` |
| Фото пары | заменить `assets/photos/couple.jpg`: квадрат 1000×1000, без посторонних людей в кадре. Если файла нет, в рамке видна подпись «Здесь будет ваше фото». Сейчас рамка одна; для нескольких фото её нужно доработать, например в фотоленту как в референсе |
| Контакты | `js/config.js`, список `contacts` |
| Время и пункты программы | `index.html`, секция `plan`; время также в `assets/svadba-denis-veronika.ics` |
| Фото цветов вместо нарисованной ткани | `index.html`, секция `dress`: заменить `<svg class="folds">` на `<img>`, стиль уже есть; фото положить в `assets/` |

## Запуск на компьютере

```bash
python -m http.server 5173
```

Открыть http://localhost:5173. Адрес с `#` в конце, например `/#anketa`, пропускает конверт, это удобно при правках. В Claude Code тот же сервер запускается через `.claude/launch.json`, конфигурация `site`.

## Анкета и Google Таблица

1. Страница отправляет POST на адрес `rsvpEndpoint` из `js/config.js`. Тип `text/plain` выбран специально: так браузер не делает предварительный запрос, который Apps Script не поддерживает.
2. Скрипт записывает строку и отвечает `{"ok":true}`. Страница показывает благодарность только после такого ответа.
3. Через 25 секунд без ответа гость видит ошибку и может отправить анкету снова. Если сеть оборвалась после записи, в таблице появится дубль.
4. Если `rsvpEndpoint` пустой, анкета ничего не отправляет и прямо об этом сообщает.

Настоящая отправка проверена: строки приходят в таблицу.

**Изменение скрипта.** Отредактировать код в Apps Script, затем «Управление развертываниями → Изменить → Новая версия». Новое развёртывание создавать нельзя, у него будет другой адрес. Если адрес всё же сменился, обновить его в `js/config.js`.

**Защита.** Адрес анкеты виден в коде страницы, поэтому отправить её может любой. Скрипт проверяет обязательные поля, обрезает ответы до 500 символов и не даёт тексту сработать как формула. Читать таблицу через этот адрес нельзя. При тестах используйте подменённый `fetch`, чтобы не засорять настоящую таблицу.

## Решения

- **Скилл оформления.** В `.claude/skills/landing-page-design` лежит скилл для лендингов. Часть его правил осознанно нарушена, потому что это свадьба и русский язык: используются курсив, Cormorant и рукописный Great Vibes рядом с Manrope, кнопки просторнее для пальцев, в текстах есть дефисы. Навигации нет, страница короткая.
- **Фоны и план вечера.** Полосы программы плоские и немного густеют от 16:30 к 23:00, но остаются светлыми. На каждой полосе появляется своя картинка.
- **Живые детали.** Картинки выезжают при прокрутке, трубка качается на шнуре, идёт обратный отсчёт по секундам, в финале плывут сердечки. Бесконечные анимации работают, только пока блок виден, и отключаются при настройке «меньше движения».
- **Индексация.** Стоит `noindex`, потому что это личное приглашение. Само содержимое при этом публично: открытый репозиторий и сайт видны всем, включая телефон и адрес.

## Особенности рабочей среды

- Windows. `codex` и `npm` в PowerShell блокируются политикой скриптов, их запускают через Bash.
- `curl` на этом компьютере иногда падает с ошибкой защищённого соединения, хотя браузер работает. Адреса лучше проверять в браузере.
- Панель браузера в приложении, если скрыта, показывает неверный размер окна. Анимацию и вёрстку надёжнее снимать через Edge без окна (`--headless=new`, протокол отладки).
- В Git Bash аргументы вроде `/exec` превращаются в путь Windows, поэтому `grep` с таким шаблоном может ошибочно ничего не найти.
- Вспомогательные тестовые скрипты лежали во временной папке сессии и в проект не входят.
- Картинки генерируются через Codex по правилам из `~/.claude/image-generation.md`, запуск через Bash. Белый фон у предметов убран скриптом, поэтому на светлых страницах они лежат без рамки.
